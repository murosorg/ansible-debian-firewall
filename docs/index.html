ROUTING

Operational clarity

Standard Debian packages and services with transparent configuration and predictable execution.

OPERATIONS
Operate with confidence

Designed for the full lifecycle.

Secure defaults, encrypted secrets and repeatable validation from first deployment to daily operations.

Base services

Chrony and rsyslog are installed and managed consistently on every firewall node.

Secrets protection

StrongSwan credentials use inline Ansible Vault values and never require committed passwords.

Continuous validation

Linting, syntax checks and Molecule tests protect changes before they reach production.

Controlled failover

VRRP and conntrack synchronization support one-node-at-a-time maintenance.

Transparent policy

Firewall rules remain readable, reviewable and traceable in version control.

Debian native

Standard systemd services and Debian packages keep the platform understandable.

Open by design

Own the configuration.
