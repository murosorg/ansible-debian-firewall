Ansible collection

Turn Debian into a managed firewall.

Debian Firewall is a collection of Ansible roles for deploying and operating a secure Linux firewall. Configure the system declaratively, keep changes reviewable and manage the complete network stack from one playbook.

View on GitHubRead the documentation

What it manages

nftables

Stateful packet filtering, NAT, sets and firewall policy.

Network

Interfaces, routes, VLANs and system network configuration.

VPN

WireGuard, IPsec and secure site-to-site connectivity.

High availability

Keepalived, conntrackd and resilient firewall services.

Routing

FRRouting and dynamic routing for managed deployments.

Debian native

systemd, apt and standard Linux tooling without a custom distribution.
