Ansible firewall automation for Debian

Firewall infrastructure, defined as code.

Deploy and operate a secure Debian firewall with repeatable roles for nftables, routing, VPN, network services and high availability.

Example playbook
$ansible-playbook site.yml

- hosts: firewalls
  become: true
  roles:
    - network
    - nftables
    - wireguard
    - strongswan
    - frr
    - keepalived
    - conntrackd
What you can automate

One collection. The whole perimeter.

Use standard Debian components and manage the result from a version-controlled playbook.

nftables

Stateful filtering, NAT, aliases, logging and rule policy.

networkd

Interfaces, VLANs, routes, bridges and Debian network configuration.

WireGuard and IPsec

Encrypted tunnels, peers and controlled administrative access.

FRRouting

Dynamic routing, policy routing and multi-site connectivity.

Keepalived and conntrackd

High availability, state synchronization and failover.

systemd and apt

Native Debian services, packages and operational tooling.
